# Deadly Dungeon — เอกสารออกแบบ (Design)

เกมบอร์ด "Deadly Dungeon" เล่นหลายคนผ่านเว็บ (สูงสุด 6 คน) เข้าห้องด้วย **รหัสห้อง + คีย์ห้อง**
รันด้วย Node.js + WebSocket หน้าเว็บเป็นภาษาไทย ไม่มี build step (static client เสิร์ฟจาก server ตัวเดียว)

---

## 1. กติกาที่ตกลงกับเจ้าของเกม (สรุปจากบทสนทนา)

- **บอร์ด**: สุ่มขนาด 6×6, 7×7 หรือ 8×8 (โฮสต์เลือก หรือสุ่ม) การันตีว่าห้องที่ทะลุได้เชื่อมถึงกันทั้งหมด (ไม่มีโซนถูกปิดตาย)
- **ห้อง 2 แบบ**:
  - **ห้องตัน (กำแพง)**: ทะลุผ่านไม่ได้
  - **ห้องทะลุได้**: มีเลขสุ่ม 1–99 **ไม่ซ้ำกัน**; เมื่อเดินเข้าไประบบจะบอกเลขห้องนั้น และบอกประตูที่ไปต่อได้
- **ประตูสุ่ม**: ห้องทะลุได้ที่ติดกันไม่จำเป็นต้องมีประตูถึงกัน — สุ่มว่าด้านไหนเปิด/ปิด ประตูเปิดทั้งสองฝั่งเสมอ (A เปิดขวาไป B ↔ B เปิดซ้ายมา A) และการันตีว่าทุกห้องเดินถึงกันได้
- **การชนะ**: ตอบเลขของทุกห้องได้ถูกต้องครบทั้งหมด ทำได้เฉพาะใน **ห้องพิเศษ (ห้องชนะ)**
- **ห้องชนะ**: คนแรกที่เดินเข้า (และยังมีชีวิต) จะได้ยื่นคำตอบเลขทุกห้อง → ถูกหมด = ชนะทันที; ผิด → ห้องชนะเดิมกลายเป็นห้องธรรมดา และ**สุ่มห้องธรรมดาอีกห้อง (ไม่ใช่ห้องเดิม) เป็นห้องชนะใหม่** (เกมยังชนะได้ต่อ)
- **ปีศาจ**: 1 ตัว เดินแบบสุ่ม 1 ช่อง ผ่านประตูเหมือนผู้เล่น เริ่มเดินตั้งแต่รอบ (round) ที่ 2 และเดินเมื่อผู้เล่นทุกคนเดินครบแล้ว — **เดินทุก 1 / 2 / 3 รอบ ตามที่โฮสต์เลือกตอนสร้างห้อง** (ค่าเริ่มต้น 2); ใครที่ปีศาจเดินไปเจอในห้อง หรือเดินเข้าห้องที่ปีศาจอยู่ = ตายทันทีกลายเป็นผี
- **เตือนปีศาจ**: ระบบเตือนทุกคน (ไม่บอกชื่อ) เมื่อปีศาจอยู่ในระยะ 1 ช่องรอบตัวผู้เล่นที่ยังมีชีวิตคนใดคนหนึ่ง (นับช่องทแยงด้วย)
- **ซ่อนสถานะตาย**: ไม่มีใครรู้ว่าใครตาย/มีชีวิต (รายชื่อ, บันทึกเหตุการณ์, ไอคอนบนกระดาน, หน้าต่างไอเทม) — รู้ได้เฉพาะตอนเจอตัวกัน หรือเกมจบ
- **ทุกคนตาย = ปีศาจชนะ**: ผู้รอดชีวิตตายหมด (หรือออกจากเกม) → เกมจบทันที
- **ผี**: ชนะเกมไม่ได้ แต่เดินต่อได้ (1 ช่อง/ตา, **ไม่สนประตู/กำแพง**, แต่ไม่เกินขอบแมพ), **รู้ตำแหน่งปีศาจเสมอ**, และเมื่อเจอผู้เล่นจะคุยส่วนตัว + **ขายข้อมูล / ทำสัญญา** ได้ สัญญามีผลผูกพันถาวร (ระบบบังคับ)
  - ผีให้ได้: **เลขห้อง** และ/หรือ **แผนที่ทางเดิน (ประตู)** ของห้องที่เลือก, หรือ **ตำแหน่งปีศาจ**
  - แลกกับ: **ชนะร่วม** (ถ้าผู้เล่นชนะ ผีชนะด้วย) หรือ **สัญญาชุบ** (ใบชุบใบแรกที่ผู้เล่นใช้ ต้องชุบผีคนนั้น)
- **ใบชุบ**: ต้องใช้ **ก่อนเริ่มเดิน** ในตานั้น; กดใช้แล้วจะเห็นรายชื่อคนที่ตายอยู่ (เห็นเฉพาะคนถือใบ) — ยังไม่ชุบก็เก็บไว้ได้
- **ห้องคำถาม**: เข้าไปแล้วตอบคำถามความรู้ทั่วไป (ยาก, 4 ตัวเลือก) → ตอบถูกได้ไอเทมสุ่ม, ตอบผิด (หรือหมดเวลา) ห้องกลายเป็นห้องธรรมดา (ใช้ได้ครั้งเดียวต่อห้อง)
- **ไอเทม**: ได้จากห้องคำถาม
- **การเดิน**: 1 ตาเดินได้ 1 ช่อง (ผลัดกันทีละคน) แล้วกด "จบตา"; ปีศาจเดินหลังทุกคนเดินครบ
- **จับเวลา**: ตาละ **120 วินาที** นับรวมหน้าต่างที่เปิดในตานั้น — หมดเวลา: คำถามที่ยังไม่ตอบ = ผิด, ห้องชนะ = ปิดไม่ยื่น, เจอกัน = จบการสนทนา แล้วจบตาให้อัตโนมัติ
- **เจอกัน**: ผู้เล่น (หรือผี) 2 คนขึ้นไปอยู่ห้องเดียวกัน = เกมหยุดให้คุยส่วนตัว (แชทเรียลไทม์) ก่อน แล้วค่อยเล่นต่อ
  - ผู้เล่นที่ยังมีชีวิตด้วยกัน: **แชร์ให้** (อีกฝ่ายได้ทันที) หรือ **เสนอแลก** (ต่างคนต่างตั้งข้อเสนอ เห็นแค่จำนวนห้อง+ชนิดข้อมูลของอีกฝ่าย แลกจริงเมื่อยืนยันทั้งคู่ แก้ข้อเสนอ = ต้องยืนยันใหม่, อีกฝ่ายกด **ปฏิเสธการแลก** ได้) — เลือกได้ว่าให้เลขห้อง และ/หรือ ประตู
  - "พันธมิตร" ไม่มีผลในระบบ ตกลงกันเองในแชท
- **บันทึกเหตุการณ์**: ไม่บอกเลขห้อง/ตำแหน่ง (ไม่ให้คนอื่นได้ข้อมูลฟรี) และไม่ประกาศการตาย/การชุบ/สัญญา
- **สมุดจดส่วนตัว**: จดเดาเลข/กำแพงบนช่องที่ยังไม่รู้ + โน้ตอิสระ (เห็นคนเดียว เก็บในเบราว์เซอร์) — หน้ายื่นคำตอบเติมให้อัตโนมัติ
- **กลับเข้าเกม**: รีเฟรช/เน็ตหลุด กลับเข้าเกมเดิมได้ภายใน 3 นาที
- **หน้าสรุปตอนจบเกม**: สถิติทุกคน + สัญญากับผี + เฉลยกระดาน
- **เข้าห้อง**: รหัสห้อง (ID สาธารณะ) กับ คีย์ห้อง (รหัสลับ) เป็นคนละอย่าง — ผู้สร้างตั้งคีย์ไว้ คนเข้าร่วมต้องใส่ทั้งรหัสและคีย์

## 2. การตัดสินใจออกแบบที่ผมเลือกเอง (สมมติฐาน — แก้ได้ถ้าต้องการ)

สิ่งเหล่านี้เป็นจุดที่กติกาต้นทางไม่ได้ระบุชัด ผมตัดสินใจเองเพื่อให้เล่นได้จริง โปรดบอกถ้าอยากเปลี่ยน:

1. **Fog of war (หมอกสงคราม)**: ผู้เล่นไม่เห็นทั้งแผนที่/เลขทันที ตอนยืนในห้องจะเห็น: เลขห้องตัวเอง + ประตูที่เปิด (คือห้องทะลุที่ติดกัน) + กำแพงที่ติดกัน + ขอบแมพ กล่าวคือเห็นเฉพาะห้องที่เคยไป + ช่องรอบๆ ที่เคยสำรวจ เลขห้องจะรู้ก็ต่อเมื่อเดินเข้าไปเท่านั้น
2. **ตำแหน่งผู้เล่นอื่น/ผี**: มองเห็นได้บนแผนที่เฉพาะช่องที่ตัวเราสำรวจแล้ว (ช่องที่ยังเป็นหมอกจะไม่เห็นใคร) และทุกคนแสดงเหมือนกัน (ไม่บอกว่าเป็นผี) — ผีที่ยืนอยู่ในกำแพงจะไม่ส่งตำแหน่งให้คนอื่น เพราะจะฟ้องว่าตายแล้ว
3. **ตำแหน่งปีศาจ**: ผู้เล่นเป็นๆ มองไม่เห็น มีแต่ **ผี** ที่เห็นเสมอ (และขายข้อมูลนี้ได้)
4. **ห้องเริ่มของผู้เล่นแต่ละคน**: มีเลขปกติเหมือนห้องอื่น (ผู้เล่นรู้เลขห้องเกิดของตัวเองทันที) — ตามที่เจ้าของเกมยืนยันภายหลัง
5. **ห้องคำถามมีจำนวนจำกัด**: วางไว้ ~6 ห้อง ใช้แล้วหมด (ตอบถูกหรือผิด ห้องกลายเป็นห้องธรรมดา) ส่วน **ห้องชนะ** ย้ายตำแหน่งไปเรื่อยๆ เมื่อตอบผิด
6. **ปีศาจฆ่าเฉพาะผู้เล่นเป็นๆ**: เดินไปห้องเดียวกับผู้เล่นเป็น = ฆ่าทันที (ถ้ามีหลายคนในห้องเดียวกัน ฆ่าทุกคน) ผีไม่ตายซ้ำ
7. **เจอกัน = หยุดเกมทั้งกระดาน**: เปิดโมดัลแชทส่วนตัวระหว่างผู้ที่อยู่ห้องเดียวกัน (รวมผี) จนกว่าฝ่ายใดฝ่ายหนึ่งกด "จบการสนทนา" หรือหมดเวลาของตา; ข้อเสนอแลกที่ยังไม่ยืนยันหมดอายุเมื่อจบการสนทนา และแชทของการเจอกันครั้งก่อนจะถูกล้าง
8. **สัญญาผี**: ผีเสนอ "ให้ข้อมูล (เลขห้อง / ประตู / ตำแหน่งปีศาจ)" แลกกับ "ชนะร่วม" หรือ "สัญญาชุบ" — ผู้เล่นกดตกลงจึงมีผล (ข้อมูลส่งทันที) ถ้าผู้เล่นที่ผีทำสัญญา "ชนะร่วม" ชนะ ผีก็ชนะร่วมด้วย; "สัญญาชุบ" ระบบบังคับว่าใบชุบใบแรกต้องใช้กับผีคนนั้น สรุปสัญญาทั้งหมดตอนจบเกม
9. **ผีเดินทะลุกำแพงได้**: ไปช่องติดกันทิศใดก็ได้ (บน/ล่าง/ซ้าย/ขวา) ภายในขอบแมพ แม้ช่องนั้นจะเป็นห้องตันหรือประตูปิด เมื่อถูกชุบกลับเป็นคน ถ้าอยู่บนกำแพงจะถูกย้ายไปห้องที่ใกล้ที่สุด
10. **ไอเทมที่ออกแบบเพิ่ม** (ดูหัวข้อ 4)
11. **สัดส่วนประตู**: สร้างทางหลักให้ทุกห้องเชื่อมกันก่อน แล้วเปิดประตูเพิ่มด้วยโอกาส 35% (`EXTRA_DOOR_P` ใน `game.js` — ยิ่งน้อยยิ่งปิดเยอะ)
12. **เตือนปีศาจ**: ประกาศในบันทึกเหตุการณ์ครั้งเดียวตอนปีศาจเพิ่งเข้าใกล้ และแสดงแถบเตือนตลอดที่ยังใกล้อยู่; ผีที่อยู่ใกล้ปีศาจไม่ทำให้เตือน (ไม่งั้นจะฟ้องว่ามีคนตาย)
13. **หลุด/กลับเข้าเกม**: ระหว่างหลุด ตาของคนนั้นถูกข้ามและคนอื่นเห็นป้าย "📴 หลุด"; ไม่กลับภายใน 3 นาที = ออกจากเกม; หลุดระหว่างตอบคำถาม/ยื่นคำตอบ = ยกเลิกหน้าต่างนั้น (เกมไม่ค้าง)
14. **กดจบตาไม่ได้ระหว่างมีหน้าต่างค้าง** (คำถาม/ห้องชนะ/เจอกัน) ต้องจัดการให้เสร็จก่อน

## 3. โครงสร้าง/ระบบ

- **server/** — ตรรกะเกมทั้งหมดอยู่ฝั่ง server (server-authoritative):
  - `server.js` — HTTP + static + WebSocket, จัดการห้อง/lobby/โปรโตคอล
  - `game.js` — เกมเอนจิน (สร้างบอร์ด, เดิน, ปีศาจ, อีเวนต์, ไอเทม, สัญญา, ชนะ)
  - `questions.json` — คลังคำถาม (สร้างโดย subagent)
- **public/** — หน้าเว็บ (HTML/CSS/JS ไม่มี build):
  - `index.html`, `style.css`, `app.js`
- การสื่อสาร: WebSocket, server ส่ง "state แบบ sanitize ตามผู้เล่น" หลังทุกการเปลี่ยนแปลง + ส่ง event เฉพาะ (คำถาม/ชนะ/เจอกัน/จบเกม)

## 4. ไอเทม (9 ชนิด)

| ไอเทม | ผล |
|---|---|
| ใบชุบ (Revive) | ชุบผู้เล่นที่ตายแล้ว 1 คนกลับมาเป็นๆ (ใช้ก่อนเริ่มเดินในตานั้น; มีสัญญาชุบค้าง → ต้องชุบผีตามสัญญาก่อน) |
| ใบเร่ง (Dash) | เดินเพิ่ม 2–4 ช่องในตานี้ |
| ใบส่องเลข (Reveal Number) | เปิดเผยเลข + ตำแหน่งของห้องทะลุได้ที่ยังไม่รู้ (สุ่ม) |
| ใบส่องกำแพง (Reveal Wall) | เปิดเผยตำแหน่งห้องตันที่ยังไม่รู้ (สุ่ม) |
| ใบแช่แข็ง (Freeze) | เลือกผู้เล่น 1 คน ให้หยุดเดิน 1 ตา |
| ใบย้ายปีศาจ (Banish Demon) | ย้ายปีศาจไปห้องสุ่ม |
| ใบรับรู้ปีศาจ (Demon Sense) | เห็นตำแหน่งปีศาจตลอดเกมที่เหลือ |
| ใบโล่ (Shield) | กันปีศาจฆ่าได้ 1 ครั้ง (หายไปเมื่อใช้) |
| ใบวาร์ป (Warp) | วาร์ปไปห้องที่เคยไปแล้ว |

## 5. ลำดับตา (Turn)

1. ผู้เล่นผลัดกันทีละคนตามลำดับการเข้าร่วม (ผู้เล่นเป็น = เดิน 1 ช่องผ่านประตู + ใช้ไอเทมได้; ผี = เดิน 1 ช่องทะลุกำแพง/ประตูปิด + ใช้ความสามารถ/สัญญา) — ข้ามคนที่ถูกแช่แข็งหรือหลุดอยู่; แต่ละตามีเวลา 120 วินาที
2. เดินเข้าไปแล้ว: เปิดเผยเลข + ประตูของห้อง → ตรวจปีศาจ (ถ้าเจอ = ตาย) → ตรวจอีเวนต์ (ห้องชนะ/ห้องคำถาม) → ตรวจเจอผู้เล่นอื่น (หยุดคุย) → อัปเดตคำเตือนปีศาจ
3. กด "จบตา" (หรือหมดเวลา) → คนถัดไป
4. เมื่อทุกคนเดินครบ → ปีศาจเดิน (ตั้งแต่รอบ 2 ทุก 1–3 รอบตามที่ตั้ง) → ขึ้นรอบใหม่
5. ผู้รอดชีวิตตายหมด → ปีศาจชนะ / มีคนยื่นคำตอบถูกหมด → ผู้ชนะ (+ผีที่ชนะร่วม) → หน้าสรุป
